# W11 파일 정리기 — 제작 요청문

11주차 2강에서 Claude Code에 보내는 실제 요청문입니다. 이 요청으로 `organize.py`가 만들어졌습니다.

## 제작 요청문

```
연습폴더의 파일을 종류별로 정리하는 파이썬 프로그램 organize.py를 만들어 주세요.

- organize.py와 같은 폴더에 있는 연습폴더가 입력입니다. 그 바로 아래의 파일만 처리합니다.
- 사진 파일(jpg, jpeg, png, gif, heic)은 출력/images 폴더로,
  문서 파일(pdf, txt, docx, hwp)은 출력/docs 폴더로,
  나머지는 출력/etc 폴더로 복사해 주세요.
- 원본은 옮기거나 지우지 말고 복사만 해 주세요.
- 같은 이름의 파일이 이미 있으면 덮어쓰지 말고 이름 뒤에 (2), (3)처럼 번호를 붙여 주세요.
- 실행하면 정리 전 파일 목록, 파일마다 어디로 복사했는지, 마지막에 종류별 개수를 보여 주세요.
- 연습폴더가 없으면 안내 문구를 보여 주고 멈춰 주세요.
- 파이썬 기본 기능만 사용해 주세요.
```

## 개선 요청문의 예 (3강)

```
숨김 파일까지 기타 폴더로 복사되고 있습니다.
이름이 점으로 시작하는 파일은 정리 대상에서 빼 주세요.
고친 뒤에는 연습폴더로 다시 시험해서 정리 전 목록과 복사 위치를 다시 보여 주세요.
```

## 연결

- 결과 코드: `organize.py`
- 첫 실행 기록: `출력.txt`
- 입력: `연습폴더/`, 결과: `출력/`
