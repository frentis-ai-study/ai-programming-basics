# W11 · 다운로드 폴더를 모사한 파일 정리 실습

실제 개인 `Downloads`는 사용하지 않습니다. 이 폴더의 `연습폴더/`가 여러 종류의 다운로드 파일이 섞여 있는 **모사 입력 폴더**입니다. 준비부터 실행·결과 확인까지 이 폴더 안에서 진행합니다.

## 준비된 입력

- `고양이.png`, `여행.jpg`: 실제로 열리는 합성 연습 이미지(실제 사진 아님).
- `메모.txt`, `보고서.pdf`: 연습 메모와 실제로 열리는 합성 PDF.
- `data.zip`: 실제로 열리는 ZIP. 안에 안내문과 작은 CSV가 있습니다.
- `downloads-template/`: 다시 연습할 때 참고할 동일 입력 5개의 원본 사본.

기존 교안의 파일명과 **이미지 2개·문서 2개·기타 1개**를 유지했습니다. 기존 로컬 자료는 확장자만 바꾼 텍스트였지만, 여기의 입력은 해당 형식으로 실제 열립니다. 실습용 합성 자료이며 개인정보·실제 고객 자료는 없습니다.

## 실행

이 README가 있는 폴더에서 실행합니다. Python 기본 기능만 사용합니다.

```bash
python3 organize.py
# uv를 쓰는 경우
uv run python organize.py
```

원본은 그대로 두고 다음 위치로 **복사**합니다.

```text
출력/images/고양이.png
출력/images/여행.jpg
출력/docs/메모.txt
출력/docs/보고서.pdf
출력/etc/data.zip
```

파일별 위치와 `정리 완료: 이미지 2개, 문서 2개, 기타 1개`가 표시되는지 확인합니다. `baseline-output.txt`와 `출력.txt`는 같은 기존 교안의 보관 실행 기록이며 이번 실행의 출력은 아닙니다. 원본 `프롬프트.md`가 가리키는 `출력.txt`도 함께 제공해 기존 참조를 유지했습니다.

## 촬영·재실행

1. Finder/파일 탐색기로 `연습폴더`를 열어 다섯 종류의 입력을 보여 줍니다.
2. 위 명령을 실행하고 터미널의 분류 결과를 확인합니다.
3. `출력`의 세 하위폴더와 원본이 그대로 남은 모습을 보여 줍니다.
4. 다시 실행하면 기존 결과를 덮어쓰지 않고 `(2)`, `(3)`처럼 번호가 붙습니다.
5. 첫 실행 화면을 다시 촬영하려면 이 실습 폴더 안의 `출력`만 다른 이름으로 보관한 후 다시 실행합니다. 실제 Downloads나 다른 업무 폴더를 삭제·이동하지 않습니다.

`organize.py`는 기존 교안과 연결된 코드 그대로입니다. 입력 폴더 바로 아래 파일만 처리하며 하위폴더는 건너뜁니다. **숨김 파일 제외는 아직 구현되지 않았습니다.** `프롬프트.md`의 3강 개선 요청은 후속 과제이지 현재 코드의 기능이 아닙니다.

검증 코드는 AI 제작 과정에서 비교·확인하는 자료입니다. 요청문 예시를 그대로 제출해도 매번 같은 AI 응답을 보장하지 않습니다.
