# 터미널 계산기

두 수와 연산자(`+`, `-`, `*`, `/`)를 입력하면 계산 결과를 보여 주는 프로그램입니다. 숫자가 아닌 값, 지원하지 않는 연산자, 0으로 나누는 경우도 안내합니다. 한 번 계산한 뒤 `y`를 입력하면 계속 계산할 수 있습니다.

## 실행 방법

이 폴더에서 다음 명령을 실행합니다.

```bash
uv run python calculator.py
```

화면의 안내에 따라 첫 번째 수, 연산자, 두 번째 수를 차례로 입력합니다. 계산을 끝내려면 계속 여부를 물을 때 `n`을 입력합니다.

## 필요한 패키지

추가 패키지는 없습니다. 파이썬 기본 기능만 사용합니다.

## 예상 결과

예를 들어 `8`, `+`, `5`를 차례로 입력하면 `결과: 13`이 나옵니다. `9`, `/`, `0`을 입력하면 `결과: 0으로 나눌 수 없습니다.`가 나옵니다.

실제 실행으로 확인한 전체 화면은 `출력.txt`에 있습니다.
