# W14 · 기록 대시보드

12주차의 날씨 기록과 13주차의 결과 파일을 한 화면에서 보는 Streamlit 대시보드입니다. 14주차 교안과 같은 예제입니다.

`requests/`의 요청문 네 개를 두 CSV 파일이 있는 폴더에서 Claude Code에 차례로 보내 만들었습니다(2026-10-07). 같은 요청문을 보내도 Claude Code가 만드는 코드는 달라질 수 있습니다. 이 폴더의 코드는 자신의 결과와 비교해 보는 견본이며 정답이 아닙니다.

## 파일

| 파일 | 내용 |
|---|---|
| `dashboard.py` | 네 번째 요청까지 반영한 대시보드입니다 |
| `forecast_records.csv` | 12주차 예제의 날씨 기록 4줄입니다 |
| `keywords.csv` | 13주차 예제의 결과 10줄입니다 |
| `requests/` | Claude Code에 보낸 요청문 네 개입니다(첫 화면, 요약과 그래프, 개수 고르기, 화면 다듬기) |
| `stages/` | 첫째, 둘째, 셋째 요청 직후의 `dashboard.py`입니다 |
| `screens/` | 단계마다 실제로 실행해 캡처한 화면입니다 |

## 실행

이 폴더에서 실행합니다.

```bash
uv run --with streamlit --with pandas streamlit run dashboard.py
```

브라우저에서 `http://localhost:8501`이 열립니다. 저절로 열리지 않으면 주소창에 입력합니다. 끝낼 때는 터미널에서 Ctrl+C를 누릅니다. 앞 단계의 화면을 보려면 `stages/`의 파일을 이 폴더로 복사해 같은 방법으로 실행합니다.

## 확인해 볼 것

- 왼쪽 표의 네 줄과 오른쪽 표의 열 줄이 두 CSV 파일의 내용과 같은지 확인합니다.
- 요약의 값(기록한 날 수, 가장 높은 최고기온, 가장 낮은 최저기온, 가장 많이 나온 말)을 표에서 직접 찾아 대조합니다.
- 말의 개수를 바꾸어 막대그래프만 바뀌는지 확인합니다.
- `keywords.csv`를 잠시 다른 곳으로 옮기고 화면을 다시 열면, 오른쪽에 안내가 나오고 왼쪽은 그대로인지 확인합니다.

## 알아 둘 점

대시보드는 두 파일을 읽어서 보여 줄 뿐이며 파일의 내용을 바꾸지 않습니다. 셋째 요청까지의 날씨 그래프는 기록이 없는 날짜까지 선으로 이어져 있었고(`screens/2-summary-and-charts.png`), 화면을 본 뒤 네 번째 요청으로 점 그래프로 바꾸었습니다. 날씨 기록은 Open-Meteo의 예보 값입니다(CC BY 4.0).
