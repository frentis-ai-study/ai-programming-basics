# W14 통합 대시보드 — 자료 연결 예제

1차시에서 정한 요구사항(도시 입력·날씨 조회·보관 메모 읽기·안전 조건)을 **AI에게 단계별로 요청해 만든 예제**입니다. W12·W13에서 만든 결과를 한 화면에서 확인하는 통합 단계입니다.

## 구성

| 파일 | 역할 |
|------|------|
| `data_sources.py` | 2단계 — 날씨 조회와 보관 CSV 읽기 함수만 담당 |
| `app_dashboard.py` | 3단계 — 첫 화면 위에 요약·표·그래프·CSV 저장과 메모 읽기를 연결 |
| `data/keywords.csv` | 학생 공통 입력 자료 — W13에서 검증해 저장한 표현별 횟수(16행, 합계 36) |
| `requests/stage2-student.txt` | 2단계 학생용 요청문 예시 |
| `requests/stage3-student.txt` | 3단계 후속 요청문 예시 |

## 이 코드의 성격

- **검증 코드는 비교용입니다.** 여기 있는 두 Python 파일은 강사가 검증한 AI 생성 예제이며, 여러분이 각자 AI에 요청해 만든 코드와 비교·확인하는 기준입니다. 모범답안을 그대로 복사하는 실습이 아닙니다. 여러분의 코드는 파일 구성·함수 이름·안내 문구가 달라도 됩니다.
- 입력 자료(`data/keywords.csv`)는 공통으로 제공됩니다. 날씨는 서울·부산·제주만 지원하고 Open-Meteo Forecast API(예보 자료, 관측값 아님)를 사용합니다.
- 요청문 예시는 학생용으로 준비한 예시이며, 실제 강사 검증에 쓴 요청 전문·AI 응답·실행 근거는 수업 자료로 별도 보관합니다.

## 실행

Python 3.11 이상, Streamlit이 필요합니다.

```bash
python3 -m streamlit run app_dashboard.py
```

- 도시에 서울·부산·제주를 입력하고 확인 버튼을 누르면 날짜별 최고·최저기온 표와 그래프가 나오고 `output/weather.csv`로 저장됩니다.
- **보관 메모 읽기** 버튼은 W13 보관 CSV 전체(16행)를 읽어 횟수 합계와 함께 보여 줍니다. 새로 집계하는 기능이 아닙니다.
- 빈 입력·지원하지 않는 도시는 안내만 하고 조회하지 않습니다. 조회나 파일 오류가 나면 이전 결과를 새 성공처럼 보여 주지 않습니다.

## 확인 기준 (각자 만든 코드에도 같은 기준으로 적용)

1. 빈 입력·공백만 입력하면 조회하지 않고 안내가 표시된다.
2. 서울·부산·제주 외 도시는 조회하지 않고 안내한다.
3. 날씨 결과에 날짜·기온 단위(°C)·출처가 함께 표시된다.
4. 보관 CSV는 전체 행이 그대로 표시되고, 횟수 합계가 36과 같다.
5. 실패 시 기존 `output/weather.csv`가 사라지거나 가짜 자료로 덮여 쓰이지 않는다.

## 한계

- 날씨 값은 실행 날짜에 따라 달라지는 예보 자료입니다. 특정 값이 정답이 아닙니다.
- 동시성·보안·성능 검증은 이 예제의 범위 밖입니다.
- 요청문 예시를 그대로 제출해도 AI 응답은 매번 달라질 수 있습니다.
