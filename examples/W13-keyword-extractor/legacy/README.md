# 메모 키워드 추출기

`notes` 폴더의 텍스트 파일을 모두 읽고 자주 나온 단어를 세는 프로그램입니다. 흔한 조사와 뜻이 옅은 말을 빼고, 많이 나온 단어 10개를 화면에 보여 줍니다. 전체 결과는 `출력/keywords.csv`에 저장합니다.

## 실행 방법

이 폴더에서 다음 명령을 실행합니다.

```bash
uv run --with pip python keywords.py
```

## 필요한 패키지

프로그램에 필요한 추가 패키지는 없습니다. 파이썬 기본 기능만 사용하며, 위 명령의 `pip`는 `uv` 실행 환경을 준비할 때만 사용합니다.

## 예상 결과

예제 메모 세 편에서 `문의`가 7회, `회의`가 4회로 가장 많이 나옵니다. 그 아래에 `신규`, `서비스`, `화면`, `초안`, `배송`이 각각 3회로 표시됩니다.

실행이 끝나면 전체 단어와 횟수가 담긴 `출력/keywords.csv`가 생깁니다. 직접 실행해 확인한 화면은 `출력.txt`에 있습니다.
