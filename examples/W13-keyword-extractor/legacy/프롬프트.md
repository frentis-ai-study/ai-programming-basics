# W13 키워드 추출기 — 제작 요청문

13주차 2강에서 Claude Code에 보내는 실제 요청문입니다. 이 요청으로 `keywords.py`가 만들어졌습니다.

## 제작 요청문

```
notes 폴더의 메모에서 자주 나온 단어를 세는 파이썬 프로그램 keywords.py를 만들어 주세요.

- notes 폴더의 텍스트 파일을 모두 읽어 주세요.
- 한글과 영어 단어만 골라내고, 단어 끝의 조사는 떼어 주세요.
  다만 떼고 나서 뜻이 사라질 만큼 짧아지면 그대로 두세요.
- 두 글자부터 세고, 흔한 말(오늘, 다시, 가장, 했다, 있다 등)은 빼고 세어 주세요.
- 많이 나온 단어부터 열 개를 횟수, 막대와 함께 보여 주세요.
- 전체 결과는 출력/keywords.csv 표 파일로 저장해 주세요.
  엑셀에서 한글이 깨지지 않게 저장해 주세요.
- 파이썬 기본 기능만 사용해 주세요.
```

## 개선 요청문의 예 (3강)

```
순위에 검토했다, 정리했다처럼 뜻이 옅은 말이 남아 있습니다.
흔한 말 목록에 이 단어들을 더해 주세요.
고친 뒤 다시 세어서 순위와 표 파일을 새로 보여 주세요.
```

## 연결

- 결과 코드: `keywords.py`
- 첫 실행 기록: `출력.txt`
- 입력: `notes/` (사흘 치 메모), 결과: `출력/keywords.csv`
